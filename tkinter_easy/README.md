## Описание

Небольшое приложение на Tkinter визуализирует таблицу умножения хордами
окружности. При множителе 2 огибающая линий приближается к кардиоиде,
а изменение множителя создаёт другие узоры.

## Возможности

- Главная окружность с 240 равномерно расположенными точками.
- Постепенная отрисовка главного узора: по три хорды каждые 25 мс
  (полный рисунок примерно за 2 секунды).
- Повтор анимации при изменении множителя или нажатии «Повторить».
- Интерактивный слайдер множителя от 0 до 12, включая дробные значения.
- Четыре отдельные миниатюры: множители 2, 3, 4 и 7.
- Выбор узора нажатием на миниатюру или кнопку под ней.
- Кнопка возврата к кардиоиде и масштабирование при изменении размера окна.

## Требования и запуск

Нужен Python 3.10+ с Tkinter и графическая среда Windows, macOS или Linux.
Используются только стандартные модули: `tkinter`, `math`, `colorsys`.
Устанавливать пакеты через pip не требуется.

Из корня большого проекта:

```bash
python3 tkinter_easy/main.py
```

Либо из папки мини-проекта:

```bash
cd tkinter_easy
python3 main.py
```

В Windows вместо `python3` используйте `python`.
Проверить наличие Tkinter можно командой `python3 -m tkinter`.

## Пример использования

1. Запустите приложение: узор умножения на 2 постепенно прорисуется.
2. Передвигайте слайдер, наблюдая, как меняются линии.
3. Выберите ×3, ×4 или ×7 в галерее и сравните фигуры.
4. Нажмите «Кардиоида ×2», чтобы вернуться к исходному узору.
5. Нажмите «Повторить», чтобы заново увидеть построение текущего узора.
6. Закройте окно для завершения программы.

Миниатюры показывают готовые фигуры для выбора. При изменении размера
окна прогресс главной анимации сохраняется. Отрисовка работает через
таймер `after`, поэтому окно и слайдер остаются доступными.

## Математическая идея

Пронумеруем `N` точек от `0` до `N − 1`. Для каждой точки `k` проведём
хорду к положению `(k × m) mod N`, где `m` — выбранный множитель.
Операция `mod` возвращает результат на ту же окружность.
Для дробных множителей конец хорды может лежать между отмеченными точками.

Координаты точки с номером `k` на единичной окружности:

```text
угол = 2πk / N − π/2
x = cos(угол)
y = sin(угол)
```

При `m = 2` линии образуют приближение огибающей в форме кардиоиды,
при `m = 3` — нефроиды. Рисуются именно хорды, а не отдельная кривая:
увеличение числа точек делает огибающую более отчётливой.
При `m = 0` все хорды приходят в одну точку; при `m = 1` каждая точка
соединяется сама с собой, поэтому видна только окружность с точками.
В миниатюрах используются 180 точек для уменьшения объёма отрисовки.

## Структура и оформление

```text
tkinter_easy/
├── main.py     # Точка входа
├── app.py      # Математика, рисунок и окно
└── README.md   # Инструкция и объяснение
```

Для небольшого вложенного проекта достаточно двух Python-файлов.
В `app.py` функция `multiplication_lines` рассчитывает координаты,
класс `CircleView` рисует одну окружность, а класс `App` связывает окно,
слайдер и галерею. Один класс отрисовки используется и для главного
изображения, и для миниатюр. Докстринги и комментарии написаны на русском.
