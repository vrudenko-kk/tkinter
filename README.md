## Описание проекта

Программа представляет собой интерактивное графическое приложение на Python с использованием библиотеки `tkinter`. В проекте симулируется поведение параллельного пучка фотонов, проходящих в гравитационном поле черной дыры.

Модель наглядно демонстрирует эффект гравитационного линзирования: фотоны, проходящие близко к горизонту событий, отклоняются, захватываются или улетают по искривленным траекториям в зависимости от их прицельного параметра и массы черной дыры.

---

## Функциональные возможности

### Основной функционал

- Анимация параллельного пучка из 25 фотонов вблизи чёрной дыры.
- Расчёт искривлённых траекторий и захвата света горизонтом событий.
- Регулировка массы чёрной дыры слайдером от 0 до 8 M₀.

### Дополнительный функционал

- Пауза, продолжение и перезапуск волны фотонов.
- Изменение скорости воспроизведения от 0.25× до 3×.
- Показ и скрытие рассчитанных траекторий.
- Отображение горизонта событий, фотонной сферы и числа захватов.
- Масштабирование сцены при изменении размеров окна.
- Управление с клавиатуры и автоматические тесты математической модели.

## Требования к системе

- **Python:** 3.10 или выше с поддержкой Tcl/Tk.
- **Операционная система:** Windows, macOS или Linux с графической средой.
  Работа окна проверена на macOS; Windows и Linux отдельно не проверялись.
- **Библиотеки:** только стандартные модули Python — `tkinter`
  (включая `ttk`), `dataclasses`, `math`, `time`; для тестов — `unittest`.
- **Сторонние Python-пакеты:** не требуются.
- **Размер окна:** минимум 850 × 580 пикселей.
- **Git:** нужен для клонирования репозитория; при скачивании ZIP необязателен.

## Установка и запуск

### 1. Получение проекта

В терминале выполните:

```bash
git clone https://github.com/vrudenko-kk/tkinter.git
cd tkinter
```

Альтернатива: скачайте ZIP репозитория, распакуйте его и откройте терминал
в папке, содержащей `main.py`. Если проект уже скачан, используйте эту папку.

### 2. Создание и активация виртуального окружения

**Windows (командная строка cmd):**

```bat
python -m venv venv
venv\Scripts\activate.bat
```

**Windows (PowerShell):**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Если PowerShell запрещает запуск скрипта активации, воспользуйтесь
инструкцией для cmd.

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

Дальнейшие команды выполняются в активированном окружении из папки проекта.

### 3. Проверка Tkinter и установка зависимостей

```bash
python -m tkinter
```

Должно открыться тестовое окно Tcl/Tk. Закройте его перед запуском проекта.
Если модуль отсутствует, установите Python с поддержкой Tcl/Tk.
В Ubuntu/Debian системный компонент устанавливается командой:

```bash
sudo apt install python3-tk
```

Tkinter не устанавливается через `pip`. Затем выполните:

```bash
python -m pip install -r requirements.txt
```

Сторонних пакетов в проекте нет: файл `requirements.txt` содержит
пояснение, поэтому эта команда ничего дополнительно не устанавливает.

### 4. Запуск программы

```bash
python main.py
```

Откроется окно «Чёрная дыра · Лаборатория света», анимация начнётся
автоматически. Для завершения закройте окно обычной кнопкой окна.

### 5. Управление

- **Масса**: от 0 до 8 условных единиц M₀. При нуле лучи прямые.
  Через 150 мс после остановки слайдера пучок пересчитывается и запускается
  заново. Состояние паузы сохраняется.
- **Скорость**: темп воспроизведения от 0.25× до 3×, без изменения геометрии.
- **Пауза / Продолжить** или **Пробел**: остановка и продолжение анимации.
- **Заново** или **R** в английской раскладке: вернуть фотоны к источнику.
- **Траектории**: показать или скрыть рассчитанные пути.
- Размер окна можно менять: масштаб обеих осей одинаков, окружности
  остаются окружностями.

Бирюзовые следы и светлые точки обозначают фотоны, золотая окружность —
горизонт событий, пунктир — фотонную сферу. Счётчик показывает число
захватываемых траекторий в текущем пучке, а не накопленное число фотонов.
После завершения волны начинается следующая. Слабые линии показывают
весь рассчитанный путь, поэтому результат виден даже на паузе.

### Обоснование структуры

Выбрано разделение модели, отображения и управления. `Model` не зависит
от Tkinter и проверяется без окна. `Renderer` отвечает только за рисунок,
`Controls` объединяет виджеты, а `App` связывает их через обработчики.
Это позволяет менять оформление без вмешательства в численный метод.
`PhotonPath` хранит результат расчёта как неизменяемые данные.
Файлы `__init__.py` обозначают пакеты Python.

Траектории рассчитываются при изменении массы, а не на каждом кадре.
Таймер `after(16, ...)` не блокирует цикл обработки событий. Время между
кадрами измеряется через `perf_counter`; задержки ограничиваются, чтобы
после перемещения окна не возникало больших скачков.

Код использует соглашения [PEP 8](https://peps.python.org/pep-0008/)
и докстринги в стиле [PEP 257](https://peps.python.org/pep-0257/).
Математические блоки сопровождаются комментариями.

## Пример использования

### Сравнение движения света при разной массе

1. Запустите `python main.py` из активированного окружения.
2. Установите массу **0** и дождитесь пересчёта: все 25 лучей движутся
   прямолинейно, счётчик захватов равен нулю.
3. Установите массу **4**: появятся горизонт событий и фотонная сфера,
   траектории искривятся, а счётчик покажет **13 захватываемых лучей из 25**.
4. Нажмите **Пробел**, чтобы рассмотреть сцену. Снимите и верните флажок
   **«Траектории»**, чтобы сравнить следы фотонов с полными путями.
5. Нажмите **«Заново»**: волна вернётся к источнику, пауза сохранится.
   Нажмите **«Продолжить»**, затем измените скорость воспроизведения.
6. Установите массу **8**: весь выбранный пучок будет захватываться.

Этот сценарий показывает, как масса влияет на форму траекторий
и долю захваченных лучей при неизменном положении источника.

## Математика и исследование

Рассматривается невращающаяся незаряженная чёрная дыра Шварцшильда.
Используются геометрические единицы `G = c = 1`: радиус горизонта
`rₛ = 2M`, радиус фотонной сферы `r = 3M`.

Для плоской световой геодезической с сохраняющимся моментом
`L = x·v_y − y·v_x` интегрируем:

```text
dx/dλ = v_x                  dy/dλ = v_y
dv_x/dλ = −3ML²x / r⁵        dv_y/dλ = −3ML²y / r⁵
r = √(x² + y²)
```

Уравнение приведено в разделе «Schwarzschild acceleration in Cartesian
coordinates» статьи
[Rotating gravitational lenses: a kinematic approach](https://academic.oup.com/mnras/article/444/3/2470/1063426).
Радиальная форма и её связь с сохраняющимися величинами разобраны в
[учебном материале Oregon State University](https://sites.science.oregonstate.edu/physics/coursewikis/GGR/book/ggr/onull.html).
Это уравнение световых геодезических, а не ньютоновское притяжение
массивных частиц.

Начальные условия: 25 лучей из `x = −72`, координаты `y` от −36 до 36
с шагом 3, одинаковые направления `(v_x, v_y) = (1, 0)`.
Источник расположен на конечном расстоянии; начальное `y` не следует
отождествлять с прицельным параметром на бесконечности.

Система решается методом Рунге — Кутты четвёртого порядка (RK4).
Основной шаг равен 0.16, около центра он ограничен величиной `0.03r`.
При пересечении горизонта луч прекращается, конечная точка уточняется
пересечением последнего отрезка с окружностью `r = 2M`.

### Допущения и ограничения

`λ` — аффинный параметр, не время удалённого наблюдателя. Анимация
равномерно перебирает рассчитанные точки; скорость воспроизведения
условная, особенно там, где шаг уменьшен. Рисунок — координатная
схема траекторий, а не изображение с камеры и не измерение локальной
скорости света. Вращение, аккреционный диск и красное смещение не учтены.

Расчёт прекращается при выходе за область `|x| > 80`, `|y| > 48`
или после 2200 шагов. Последний предел предотвращает зависание вблизи
критических орбит: такой путь может быть обрезан до выхода из области.
Фотонная сфера показана как ориентир и сама по себе не поглощает свет.
Масса меняется между расчётами; моделирование динамически меняющейся
метрики не выполняется.

## Проверка

```bash
python -m unittest discover -v
python -m compileall -q main.py src tests
git log --oneline
```

Тесты проверяют прямые лучи при нулевой массе, зеркальную симметрию,
поглощение на горизонте, конечность координат, увеличение захвата
с массой, сходимость угла при уменьшении шага и отклонение некорректных
значений массы.

Для ручной проверки: выставить массу 0, затем 4 и 8; проверить паузу,
перезапуск, скрытие траекторий, изменение размера окна и закрытие окна
во время анимации. При массе 0 захватов нет, при 4 захватываются
13 из 25 лучей, при 8 — весь выбранный пучок.
